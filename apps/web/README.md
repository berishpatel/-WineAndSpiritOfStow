# Wine & Spirits Of Stow Web

Public frontend for Wine & Spirits Of Stow.

## Current V1 Sections

- Age verification gate
- Homepage hero with store calls to action
- Product categories
- Weekly specials
- Staff picks
- Local SEO section
- Contact, phone, directions, and hours
- Newsletter signup layout

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Notes

This V1 public site avoids checkout, delivery, shipping, or online alcohol sale claims until the business confirms legal and operational support.
